Patch Release V3.5.1 | 2026-11-02

What's New in Version 3.5.1

Version 3.5.1 is a targeted patch release that resolves critical UI visibility and folder traversal issues during multi-dataset session ingestion (simulated tracks, GTrack, and calibration files), restoring action button contrast and enabling full-card interaction.

🔘

1. Action Button Visibility & Contrast

load_folder.js

Eliminated white-on-white invisible buttons caused by Tailwind CDN observer detachment.

  • •
    Bulletproof CSS Rule: Added dedicated .load-pair-btn styles in index.html with explicit colors (#1e293b in light mode, #374151 in dark mode), 100% independent of Tailwind JIT state.
  • •
    Preflight Reset Immunity: Overrides Tailwind's transparent button reset, guaranteeing prominent, elevated action buttons on both white and dark modal backgrounds.
  • •
    Modal Recompile Hook: Calls window.tailwind.recompile() on modal open to ensure any dynamic utility classes are generated.
DOM & Styling 100% Contrast Recovery
👆

2. Full-Card Clickable Targets

load_folder.js

Expanded interactive click targets across entire dataset cards with responsive layouts.

  • •
    Entire Card Clickable: Transformed every pair card into an active interactive trigger with cursor-pointer, hover borders (hover:border-blue-500), and elevation shadows.
  • •
    Dual Trigger Support: Clicking anywhere on the card body OR on the action button smoothly loads the selected dataset pair.
  • •
    Anti-Squash Guards: Added flex-1 min-w-0 and responsive flex wrapping so long file paths truncate gracefully without squashing action buttons.
User Experience Effortless Selection
📂

3. Large Folder Ingestion (>100 Files)

fileLoader.js

Overcame Chromium's 100-file per-batch directory reader limitation.

  • •
    While-Loop Pagination: Wrapped dirReader.readEntries() in a recurring loop that continues until an empty array is received.
  • •
    Zero Missing Files: Prevents silent truncation in large session directories containing hundreds of tracking slices, frame dumps, or auxiliary files.
  • •
    Deep Directory Traversal: Retains full relative path integrity (file.relativePath) across complex multi-tier folder trees.
File System API Unlimited Batch Reading
🎯

4. Dataset Priority Calibration

load_folder.js

Fine-tuned priority scoring for simulation, GTrack, and calibration files.

  • •
    Simulation Detection: Updated regex to /simulat.*\.json$/i (score 85) to reliably match root and nested simulation logs.
  • •
    GTrack Prioritization: Updated regex to /gtrack.*\.json$/i (score 75) to recognize case-insensitive aligned tracks.
  • •
    Calibration Demotion: Demoted metadata and camera calibration files (radar_camera_calib.json, session_metadata.json) to score 15 so true radar telemetry always takes priority.
Ingestion Intelligence Accurate Auto-Pairing
