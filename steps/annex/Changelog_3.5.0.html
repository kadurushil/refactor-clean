Release Notes V3.5.0 | 2026-10-30

What's New in Version 3.5.0

Version 3.5.0 is a major performance engineering milestone. Based on comparative Chrome DevTools CPU & GPU profiler traces, this release eliminates severe frame drops, algorithmic bottlenecks, and layout thrashing on integrated GPU and high-DPI laptop hardware, boosting slow-machine playback from 20 FPS to a rock-solid 60+ FPS.

⚡

1. GPU Scaling & FES Suppression

radarSketch.js

Eliminated 3× overdraw on high-DPI displays and suppressed heavy runtime argument validation.

  • •
    Locked Pixel Density: Enforced p.pixelDensity(1) across radar, zoom, and speed graph canvases, preventing Windows 150%–175% scaling from tripling backbuffer pixel fill requirements on integrated GPUs (Intel UHD 620).
  • •
    Friendly Error System (FES) Disabled: Set p5.disableFriendlyErrors = true; globally before canvas instantiation, eliminating 29.2% (4.1s) CPU overhead in recursive regex validation.
  • •
    Shared Memory Bandwidth Preserved: Drastically reduced DDR4 bus contention between CPU and integrated GPU, ensuring sustained 60Hz VSync stability.
GPU & Graphics Pipeline 3.06× Fill-Rate Recovery
🚀

2. O(1) Track Frame Indexing

drawUtils.js

Replaced repetitive linear searches with pre-computed hash-map indexing and binary searching.

  • •
    Pre-computed Map Ingestion: Built track.logsByFrame = new Map() during JSON parsing, replacing O(N × M) linear scans with instant O(1) lookups.
  • •
    Centralized Helper: Exported getTrackLogForFrame(track, frameIdx), replacing repeated .find() calls across predicted positions, covariance ellipses, markers, dimensions, and FCW alerts.
  • •
    Binary Search Trajectory Slicing: Replaced whole-array filtering with O(log N) binary search (findLastLogIndexBeforeOrAtFrame) and contiguous coordinate slicing, eliminating 3.7s of per-frame GC churn.
Algorithmic Optimization O(N) → O(1) Instant Lookups
📐

3. Layout Thrashing Elimination

dom.js

Eliminated forced synchronous layout reflows during timeline scrub and playback.

  • •
    Cached Canvas Width: Cached dotCanvas.clientWidth via passive ResizeObserver and window resize listener, replacing synchronous DOM queries inside the render loop.
  • •
    Zero Forced Reflows: Eliminated 910ms of browser reflow blocking during interactive scrubbing and high-speed timeline dragging.
  • •
    Smooth Scrubbing: Scrubbing latency dropped from 17.38ms to sub-2.5ms, ensuring butter-smooth seekbar scrub tracking.
DOM & Layout Zero Reflow Overhead
🛡️

4. Tailwind Observer & DOM Guards

sync.js

Detached runtime JIT observers and suppressed redundant HUD class/text updates.

  • •
    MutationObserver Detachment: Exposed window.tailwind.disconnect() and detached observer 500ms post-boot, stopping full-DOM regex re-scans on every frame.
  • •
    ClassList Mutation Guards: Added .classList.contains('hidden') checks before modifying badges and overlays, preventing pointless DOM invalidations.
  • •
    Cached Text Content Writes: Guarded overlay text updates against rewriting identical strings, cutting per-frame DOM churn to near zero.
DOM Mutation Control 1.5s Observer Saved
