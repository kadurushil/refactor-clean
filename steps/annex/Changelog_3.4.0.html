Major Release V3.4.0 | 2026-07-24

What's New in Version 3.4.0

The 3.4.0 "Frame-Accurate Mapping & Dynamic Workspace" update introduces native frame_mapping.json temporal synchronization, dynamic video FPS detection, a segmented offset mode toggle, folder auto-pairing, GridStack workspace customization, and FCW Stage 2 warning overlays.

🎯

frame_mapping.json Engine

Sub-millisecond per-frame temporal alignment for recorded radar and video logs.

  • • Absolute Timestamp Baking: Bakes exact video timestamps into radar frames on file load for zero-overhead 60 FPS playback.
  • • O(1) Map Hash Table: Optimized lookup performance from O(N²) down to O(1) hash maps (100x precompute speedup).
  • • IndexedDB Map Caching: Retains frame_mapping.json in browser storage across page reloads.
⚡

Dynamic FPS & Mode Toggle

Smart hardware frame rate detection and intuitive offset control.

  • • Dynamic Video FPS: Automatically computes recording FPS (24, 25, 29.97, 30, 50, 59.94, 60 FPS) directly from mapping records.
  • • Human-Readable Display: Shows intuitive video lead offset (e.g. 6567 ms) derived from (video_frame / FPS) * 1000.
  • • Segmented Mode Toggle: Visual Auto (map) vs Manual mode toggle with one-click map revert.
📁

Folder Upload & Auto-Pairing

Direct folder drag-and-drop with multi-dataset discovery.

  • • Recursive Traversal: Scans entire folder trees to discover JSON logs, MP4 videos, and map files automatically.
  • • Smart Dataset Pairing: Pairs log files with video files using priority scoring rules and subfolder matching.
  • • Selection Modal (Case C): 30% larger modal layout with auto-scroll to primary recommendations.
🖥️

GridStack & FCW Stage 2

Customizable dashboard grid, ADAS inspector, and forward collision warnings.

  • • GridStack Integration: Resizable and reorderable dashboard cards with persistent layout memory.
  • • FCW Stage 2 Overlays: Draggable Forward Collision Warning overlays with real-time target distance markers.
  • • Floating Panels: Decoupled God Mode Zoom panel and Data Explorer with vertical ADAS property inspector.
🚀

Fast Seeking & Visual Sync Badge

High-speed video seek throttling, 100ms reduced debounce, and real-time visual seeking cues.

  • • Throttled Fast-Seek: Dispatches native fastSeek() every ~60ms during continuous scrubbing for near real-time video feedback alongside <1ms radar redraws.
  • • 100ms Debounce Snap: Reduced trailing seek debounce from 300ms to 100ms for instant frame snapping when seeking stops.
  • • Visual Seeking Badge: Animated seeking overlay badge on the video panel indicating active video decoding and seek state.
  • • Robust State Reconciliation: Eliminates stuck seeking badge states via post-debounce state checks, small-drift handling, and an 800ms safety fallback timer.
  • • Queued Playback Guard: Shows "Syncing..." and queues playback if Play is pressed while a seek is in progress.
🛡️

Z-Index & Defensive Stability

Robust state isolation and clean UI handle layering.

  • • Clean Z-Index Hierarchy: Managed z-index scale (panels z-40, modals z-[70], drag overlay z-[90]).
  • • State Isolation: Explicit reset of video FPS and map parameters when switching back to non-map datasets.
  • • Deferred Cache Cleanup: Prevents premature IndexedDB cache wipes during drag-and-drop cancellations.
📊

Glassmorphic Debug Badge

Real-time telemetry, cache stats, and build versioning.

  • • Floating Telemetry Badge: Glassmorphic bottom badge displaying active build version, browser, and OS.
  • • Cache Statistics: Interactive popover showing IndexedDB usage, stored blobs, and manual offsets.
  • • API Versioning: Dynamic /api/version fetch with automatic static server fallback.
